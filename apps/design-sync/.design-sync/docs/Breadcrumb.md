# Breadcrumb

The title of a nested dashboard page — one that is not a sidebar destination (a program editor, a deposit form, an application review).

Every item but the last is a link; the last item is the page's `h1` (`aria-current="page"`), so a page rendering a breadcrumb draws no other heading. Separators are decorative chevrons. A sidebar page shows no breadcrumb and no visible title. Needs a router in context, which the design system provides.
